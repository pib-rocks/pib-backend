## Goal
Add a Blockly block that plays a movement SEQUENCE OF POSES with SMOOTH TRANSITIONS (blending through the
waypoints), by calling the new pib-sdk timed trajectory API. This is the smooth variant — NOT the naive
"move to pose, stop, move to next" player.

## The pib-sdk API this block must call (added by PR-1685 in pib-sdk, PR #5)
`pib_sdk.features.poses.play_pose_sequence_timed(writer, backend, schedule, *, by="name") -> None`
- `schedule = [(pose_identifier, seconds_for_this_leg), ...]` — per-LEG duration (seconds to reach that pose
  from the previous waypoint; first entry from trajectory start). It accumulates these into absolute
  `time_from_start` internally.
- It builds ONE timed standard-layout JointTrajectory (one point per pose, positions for all joints, real
  time_from_start) and sends it, so the pib-backend software trajectory controller (PR-1660, merged:
  trajectory_executor.py, PCHIP interpolation at 100 Hz) BLENDS through the via-points instead of stopping.
- `by` is `"name"` (default) or `"pose_id"`.
- Import it as: `from pib_sdk.features.poses import play_pose_sequence_timed`
- Also available (do not change): `set_pose`, `get_pose`, `apply_pose`, `save_current_pose`, and the naive
  `play_pose_sequence` (simple mode; NOT what this block uses).
