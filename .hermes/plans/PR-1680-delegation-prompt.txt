## Goal
Add two Blockly logging blocks for a program-based, persistent log:
1. A 'log' statement block with a Loglevel dropdown (default INFO) that appends a string (from a variable/input)
   as a new line with a TIMESTAMP + SEVERITY prefix to the program's persistent log.
2. A 'reset log' statement block that clears the program's log.

## Persistence / path (confirmed design)
- The log is persistent in a file inside the `programs` container (volume-mounted, survives restarts).
- Program python files are written as `{PROGRAM_DIR}/{program_number}.py` (verified `ROS2 programs/program.py:110`,
  `PROGRAM_DIR = os.getenv("PROGRAM_DIR", "/home/pib/cerebra_programs")`; compose sets `/ros2_ws/cerebra_programs`).
- Therefore the log path (by program) is: `{PROGRAM_DIR}/program-logs/{program_number}.log`
  (e.g. `/ros2_ws/cerebra_programs/program-logs/5.log`). Unless reset, the file persists; new runs append.

## Blockly design
Add to pib-backend Blockly (follow motor_current / pose / camera_depth block+generator+test pattern;
blocks registered via DefineJSON -> custom-blocks, generators via spread -> custom-generators, Python logging
helpers in function-declarations/definitions):

### Block 1 - type e.g. `program_log`
- message: "log %1" with a Loglevel dropdown (name LEVEL) options [INFO,WARNING,ERROR,DEBUG] default INFO
  AND a string input (value input, e.g. input_value TEXT) for the message text.
- Emits Python that appends one line to the program log:
  - Path derived at runtime from PROGRAM_DIR env + current program number. The generated program runs standalone
    (saved as {PROGRAM_DIR}/{program_number}.py), so program_number can be derived from `__file__` basename
    (e.g. `os.path.splitext(os.path.basename(__file__))[0]`) OR use an env var if cleaner. Log dir:
    `os.path.join(os.getenv("PROGRAM_DIR", ...), "program-logs", "<program_number>.log")`. Ensure the
    `program-logs` directory is created (`os.makedirs(..., exist_ok=True)`).
  - Append (mode "a", utf-8) a line `[{datetime}] {LEVEL} {text}` (timestamp + severity prefix).
- Dropdown severity -> expand to the level string in the emitted line.

### Block 2 - type e.g. `program_reset_log`
- statement block "reset log": clears the program's log file (same path as above): ensure dir exists, then
  truncate/delete (write empty) so a fresh run starts empty.
