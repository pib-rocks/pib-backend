PART 1 — PR-1627: set default output volume to 100% at install (wpctl)
=====================================================================

Verified on the live Pi: `wpctl` comes from the `wireplumber` package (/usr/bin/wpctl), PipeWire +
WirePlumber are running, and the default sink currently sits at `Volume: 0.40`.

- Add a new function in `setup/setup-pib.sh` (functions are declared at the top; the main flow runs at the
  bottom of the file) named e.g. `set_default_output_volume()`.
- The function must:
  * set the volume to 100% with:  `wpctl set-volume @DEFAULT_AUDIO_SINK@ 1.0`
  * use the PipeWire alias `@DEFAULT_AUDIO_SINK@` (NOT a device name) so it works on any hardware.
  * be IDEMPOTENT (re-running the installer must not change anything / must not fail).
  * verify and log the result with `wpctl get-volume @DEFAULT_AUDIO_SINK@` (expect `Volume: 1.00`).
  * degrade gracefully: if `wpctl` is missing or PipeWire is not up yet, print a WARNING and do NOT fail the
    whole install (the ticket is an install-time default, not a hard dependency).

  work as root (see `sudo usermod -aG docker pib`). The volume step MUST run as the `pib` user with the runtime
  dir set, e.g.:
      sudo -u pib XDG_RUNTIME_DIR=/run/user/1000 wpctl set-volume @DEFAULT_AUDIO_SINK@ 1.0
  Do NOT run wpctl as root (root has no session bus / sinks -> it would silently do nothing).
- Call `set_default_output_volume || print WARN "failed to set default output volume"` from the main install
