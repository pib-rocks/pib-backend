# Implementation Plan: PR-1509 Fix motor_control startup crash on reboot

**Repository:** `pib-backend`  
**Requirement:** Jira PR-1509  
**Branch:** `PR-1509`  

## Root Cause
In `ros_packages/motors/pib_motors/pib_motors/bricklet.py`:
`successful, bricklet_dtos = bricklet_client.get_all_bricklets()` is called once on import.
When the Pi reboots, `ros-motors` starts before `flask-app:5000` (`pib-api`) is ready. The request fails with `urlopen error [Errno 111] Connection refused`, `bricklet.py` raises `RuntimeError`, and `motor_control` crashes permanently.

## Fix
In `ros_packages/motors/pib_motors/pib_motors/bricklet.py`:
Implement a retry loop with sleep/backoff (e.g., retry every 2s up to 60s total) when calling `bricklet_client.get_all_bricklets()` on startup before giving up and raising `RuntimeError`.

## Unit Tests
Create `tests/unit/test_bricklet_retry.py` verifying that transient failures in `bricklet_client.get_all_bricklets()` trigger retries and succeed once `pib-api` responds.
