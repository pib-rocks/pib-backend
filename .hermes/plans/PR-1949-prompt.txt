=== What was measured after a real fresh install (192.168.1.172, Pi 5, 8 GiB, wiped device, 2026-10-08) ===
All four defects below appeared although their install step reported "ok".

1) Hermes CLI unusable. `hermes --version` answers: "hermes: no dependency environment is committed for
   this install; run `hermes pm repair`". Inside the flask container `import hermes_cli` and
   `import hermes_constants` both fail with ModuleNotFoundError. Consequences: three voice-assistant E2E

2) Host IP missing. No file under /etc or /run, `GET /host-ip` answers HTTP 500. Consequences: both

3) marimo does not start. `systemctl is-active pib-marimo` says "activating" (it is enabled), not "active".
   Consequences: three programs_component E2E tests fail.

4) Qwen is installed and reachable but NOT offered in Cerebra. Measured: ollama active+enabled, 0.40.1,
   `ollama list` shows qwen-fast:latest and qwen2.5:1.5b (986 MB each), http://127.0.0.1:11434/api/tags
   returns both, and the install step ran (setup-pib.sh:1379 gates on pib5edu|pib5advanced|pib5museum).
   The list Cerebra offers is built elsewhere - start at pib_api/flask/service/local_model_service.py.
   This is a wiring/visibility defect, not an installation defect.

5) Undetermined: two on-device-model E2E tests fail (model lifecycle; blockly detection to a named pose).
   The model store is complete (16 blobs, all model directories), so provisioning is NOT the cause.
   Find the cause; do not guess it.

pattern matters as much as the four defects: where the script can verify a result cheaply (a version
call, a systemd unit state, an HTTP status), it must do so and fail loudly - reporting "ok" for a
missing result is what made this install look complete.
