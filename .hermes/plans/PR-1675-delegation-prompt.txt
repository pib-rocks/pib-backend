## Goal
Add two Blockly blocks that access camera depth via the pib_sdk Camera depth API (added in PR-1674, published in
pib-sdk 0.5.0):
1. A 'get depth image' block -> calls `Camera.get_depth_frame()` and yields the depth image.
2. A 'depth at (x, y)' block -> takes two number inputs x, y -> calls `Camera.get_distance_at_px(x, y)` and
   returns the distance in millimetres.

## Verified pib_sdk API (pib-sdk 0.5.0, src/pib_sdk/features/camera.py)
- `Camera(host="...", port=9090)` (rosbridge); constructor opens a rosbridge connection; `close()` / context manager.
- `get_depth_frame(timeout=10.0) -> np.ndarray | None` (uint16 mm (H,W); None on no data/error).
- `get_distance_at_px(x:int, y:int, timeout=10.0) -> float` (distance_mm; 0.0 on no cache/OOB/invalid).
- `save_depth(path, ...)`.
