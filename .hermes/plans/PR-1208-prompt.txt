Verified pib-sdk API (from the installed package, do not invent signatures):
```python
from pib_sdk import ik, Write, right_arm, left_arm

# 1) Inverse kinematics: XYZ hand position -> joint angles in DEGREES
q_deg = ik("left", xyz=[x, y, z])          # side: "left"/"right" or ArmSide; returns np.ndarray of degrees
#    optional: rpy_deg=[...], and solver opts (initial_guess_deg, tolerance, max_iterations, mask, restarts, respect_limits)

# 2) Motor control: move the arm to those joint angles
with Write(host=rosbridge_host, port=9090) as pib:
    pib.move(right_arm, *q_deg)            # angles in degrees, range [-90, 90]
```
- `ik(side, *, xyz=[...], rpy_deg=None, **solver_options)` -> np.ndarray (degrees)
- `Write(host=...)` context manager; `Write.move(*args)` moves motors (uniform or vector mode; a lone hand-action token like `open_left_hand` performs that action).
- `right_arm` / `left_arm` are the arm group tokens; `ArmSide` enum also available.
- The block should let the user choose the arm side (left/right) — add a `field_dropdown` for the side.
