## Goal
Add ONE Blockly VALUE block that returns the current sound-source direction (DOA) of the microphone array, in
degrees, so a program can react (e.g. turn the head toward the speaker).

## Verified data source
- `ros_packages/ros_audio_io/ros_audio_io/doa_publisher.py` publishes the direction on the ROS topic
  **`/doa_angle`** with message type **`std_msgs/Int32`** (`self.create_publisher(Int32, "doa_angle", 10)`),
  every `DOA_PUBLISH_INTERVAL` seconds (default **2.0 s**). So the value is at most ~2 s old and the node must
  WAIT for a message.
- Angle convention (consolidated from the duplicate ticket PR-982): **0 degrees = directly in front of the
  head**, sign distinguishes right/left. Keep the value as published (do NOT re-map it) and document the
  convention in the block tooltip.
