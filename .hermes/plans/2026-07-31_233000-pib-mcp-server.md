# Implementation Plan: PR-1506 pib MCP Server

**Repository:** `pib-backend`  
**Requirement:** Jira PR-1506  
**Branch:** `PR-1506`  

## Overview
Develop `pib_mcp_server`, a dedicated Model Context Protocol (MCP) server for pib humanoid robot capabilities (motors, poses, programs, image capture, SOUL append, relays).

## Proposed Tool Surface
- Read tools:
  - `pib_list_motors`: Enumerate motors/bricklets with current positions.
  - `pib_get_state`: Joint state, diagnostics, and telemetry snapshot.
  - `pib_list_poses`: Enumerate stored poses.
  - `pib_list_programs`: Enumerate stored programs.
  - `pib_capture_image`: Capture a camera frame as base64 / image artifact.
- Actuating tools (disabled by default):
  - `pib_move_motor`: Move a motor to a range-validated position.
  - `pib_apply_pose`: Apply a stored pose by name.
  - `pib_run_program`: Execute a stored Blockly/Python program by ID.
  - `pib_set_led` / `pib_set_relay`: Control LED and solid-state relay.
- Write tools:
  - `pib_soul_append`: Append-only self-learning entry (capped <= 500 chars).

## Phase Breakdown

### Phase 1: `pib_mcp_server` Package Core & StdIO Server
- Create `pib_mcp_server/` package (`__init__.py`, `server.py`, `__main__.py`).
- Implement MCP Server using the official `mcp.server.fastmcp.FastMCP` or `mcp.server.Server`.
- Define read-only tool handlers (`pib_list_motors`, `pib_get_state`, `pib_list_poses`, `pib_list_programs`, `pib_capture_image`).
- Define actuating and write tool handlers (`pib_move_motor`, `pib_apply_pose`, `pib_run_program`, `pib_set_led`, `pib_set_relay`, `pib_soul_append`).
- Include strict JSON input schema validation and range validation for `pib_move_motor`.

### Phase 2: Unit Tests & Runbook
- Write unit tests in `tests/unit/test_pib_mcp_server.py`.
- Write runbook at `docs/runbooks/pib-mcp-server.md`.
- Update interim skill documentation.
