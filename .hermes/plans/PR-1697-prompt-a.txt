TASK 1 - composite model entry
The pipeline manager starts one model_id, but the hand path is a chain. Add a composite entry so the
hand path can be started as ONE model:
  - extend models/manifest.yaml with a composite entry, e.g.
      - model_id: hand_tracking
        task: hand_tracking
        composite: true
        artifacts: [palm_detection_128x128, palm_detection_128x128_decoding, hand_landmark_224x224]
        publish_topic: detections/hand_tracking
    (keep every existing entry and its hashes untouched; the vendored .blob files must not change)
  - model_registry.py must resolve it: a composite model is available only if ALL its artefacts exist
    and verify, and it reports the summed size/shaves. Single-artefact models keep working exactly as before.
